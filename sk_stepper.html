SK Stepper

A local, offline tool for hand-analysing S/K terms one reduction at a time. By default, it uses leftmost-outermost reduction (normal-order reduction). It follows one term at a time, with unlimited history. Loading a new term replaces the history.

Terms

  • S, K are combinators. Lowercase letters and digits are inert atoms. Capital letters (other than S, K) are macros or families. Notation is left-associative, e.g. S(KS)K, or prefix-application form where . = application, e.g. ..SKK.

Reducing

  • Step (or Enter when no input is focused) does one leftmost-outermost step. ×10, ×100, and Run to NF (up to 5000 steps) repeat it.
  • Click a bold redex head in the latest row to contract that redex instead. It counts as a normal-order step only if it is the leftmost-outermost one. Otherwise it counts as an "other contraction".
  • Undo removes the latest row. Each row is labelled with what produced it.
  • The underline marks the redex contracted to produce the next row (in the latest row, the one a normal-order step would contract).

Cleanup (button, or the "cleanup after each step" checkbox)

Applies these rewrites anywhere in the term, repeatedly, until none apply:

  • K x y → x
  • S K x y → y
  • S (K x) y z → x (y z)
  • S x (K y) z → x z y

Each is one or two ordinary reductions that duplicate nothing and shrink the term, so cleanup never changes whether a term has a normal form or what it is. It is shown as one row ("cleanup ×n") and counted under "other contractions", never as normal-order steps.

Display

  • Each application spine sits in a rounded outline. Hovering colours the innermost outline's head and arguments by role relative to that outline's own head. Parentheses are hidden but are copied with the text. Outline gap sets the spacing between nested outlines.
  • Bold heads are redexes (S with 3+ arguments, K with 2+). A green row is a normal form. An amber row is where head normal form was first reached.
  • Rows over 10,000 leaves are shown as folded text, with no outlines.

Macros

  • Define with V = SSK in the panel, or right-click an outline → Add as macro. Right-click a macro to remove it. Names are single capitals other than S, K. A macro needs at least 2 leaves, and two macros cannot be the same term.
  • Macros are only a display layer: history rows keep the full terms, and the whole history is re-rendered when macros change. A redex entirely inside a macro is not drawn as a redex. show macros turns them off.
  • The text box lists all definitions as N = term. Edit it and press Import to replace them all. Lines starting with // are ignored. Copy it to save a set.

Inductive families

  • M* = base ; ctx defines M₀ = base and Mₙ₊₁ = ctx with # replaced by Mₙ. # may appear several times, and all slots must then hold the same term. Example: M* = DD ; S#(D(S#)). A context is always required.
  • Right-click an outline → Create inductive family pre-fills the definition.

Right-click menus

  • Outline: add as macro, start a family, Analyze this term (loads it as a new start row). Macro or family atom: remove, or analyze. Text-only row: analyze.
